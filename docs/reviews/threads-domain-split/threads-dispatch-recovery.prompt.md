## Граница этой части

Проверь уже перенесённые изменения:
- окончательный безопасный отказ, временная недоступность хранения и неопределённый результат запуска различаются типизированно;
- Rejected/Delivered подтверждают конкретную границу доставки, а не успех модели;
- accepted canonical terminal доводится до cleanup и необходимого memory sync до ACK;
- исчерпанные StartAgent не отправляются модели снова; существующее reconciliation повторяемо и соблюдает точные action/response/grant/owner/generation связи;
- после restart новый процесс может подтвердить старое canonical terminal outcome, но не получает право активировать чужое живое исполнение;
- loaded thread с unloaded target Turn не блокирует terminal replay;
- recovery terminalization и fallback не применяют старый Blocked N поверх resumed N+1; используй уже перенесённый guarded sync;
- compaction сохраняет минимальную точную связь для terminal reconciliation без восстановления пользовательского payload;
- immediate и exhausted SQL selectors согласованы с partial/expression indexes, закрытые terminal refusals не остаются в регулярно просматриваемом рабочем диапазоне;
- NULL/timed ranges, poison-row progress, attempts, квоты и bounded quantum сохраняются.

Основные файлы: outbox/reconciliation-фрагменты message/agent_action_tools.rs; recovery consumers message/agent_runtime.rs; CRUD repositories/agent_domain.rs и outbox discovery/compaction; две новые индексные миграции и Migrator.
