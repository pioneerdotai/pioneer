## Граница этой части

Проверь уже перенесённые изменения:
- delegated user-visible root имеет самостоятельный work graph и lifecycle, а исходный AgentExecution сохраняется как автор действия и provenance;
- home-capsule child остаётся настоящим потомком с прежним lifecycle;
- current admission нового root проверяется по initiating principal без расширения inherited immutable context;
- canonical action/receipt/grant/input/response образуют одну согласованную цепочку;
- первый API dispatch работает без уже существующего runtime snapshot; подготовка, registration и activation согласованы;
- реальный CLI путь использует CLI attempt и общий dispatcher;
- activation claim и replay не запускают модель повторно после неопределённого результата;
- новый root сохраняет самостоятельную identity/provenance; окончательная foreground admission и её конфликты приходят частью 3 вместе с ранним Stop;
- типизированная инфраструктурная ошибка не теряется в подготовке API/CLI-каталога и не объявляется доказанным отказом доступа.
